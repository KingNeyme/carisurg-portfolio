# My Anti-Procrastination Protocol

## The Pattern I Noticed

One task I delayed was starting work that felt unclear or had several tools involved. The real reason was not simply that I was busy. I was waiting to feel certain about every step before beginning, which made the task feel larger than it was.

## Technique: Implementation Intention

I will use a specific if-then rule:

**If I notice that I have delayed a task twice, then I will open the file, write the next physical action, and work on it for ten minutes before deciding whether to stop.**

Examples of a next physical action:

- open the assignment brief
- create the required folder
- write one heading
- import one reference
- draw the first two boxes of a workflow

## My Protocol

1. Name the task I am avoiding.
2. Write the real reason I am avoiding it.
3. Reduce the task to one action that takes under two minutes to start.
4. Set a ten-minute timer.
5. Work only on the next visible action.
6. At the end of ten minutes, record what changed.
7. Choose the next action before closing the task.

## What I Will Track

- time I noticed the delay
- the real reason
- the first action I chose
- whether I completed the ten-minute session
- the next action written for later

## Success Measure

The protocol is working if I begin important tasks earlier, reduce last-minute pressure, and leave each work session knowing exactly what comes next.
