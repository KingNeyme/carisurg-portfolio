# Week 6 Assignments

This folder contains the Week 6 baseline modelling notebook, result tables, and written support files.

## Files

| File | Purpose |
| --- | --- |
| `Week6_Baseline_Triage_Model.ipynb` | Week-specific copy of the modelling notebook |
| `week6_model_summary.csv` | Model-level comparison table |
| `week6_model_metrics.csv` | Per-class precision, recall, F1, and support |
| `week6_model_results.json` | Full reproducibility metadata and confusion matrices |
| `Clinical_Explainer_Video_Script.md` | 1-minute script for Dr. Reyes explaining why the safety metric matters |
| `Career_Challenge_CV_Review.md` | Mid-program CV review reflection and update plan |

The fitted baseline models are stored in `../models/`, and the confusion matrix images are stored in `../outputs/`.
