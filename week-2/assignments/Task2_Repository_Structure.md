# Task 2: Repository Structure

## Objective

Make the repository understandable to a clinical reviewer within 60 seconds.

## Required Structure

The Week 2 brief asks for:

- `README.md`
- `LICENSE`
- `.gitignore`
- `requirements.txt`
- `notebooks/`
- `docs/`
- `data/`

## Design Decision

This repo keeps a week-by-week portfolio structure because it is easier to review over time:

- `week-0/`
- `week-1/`
- `week-2/`
- `week-3/`

The class-required folders also exist at the root as reviewer entry points.
