# Notebooks

This folder is the class-required notebook entry point for the CariSurg portfolio repository.

The working Week 0 notebooks are organised inside the weekly portfolio folder:

- [`../week-0/assignments/Week0_Tutorial1_EnvSetup_and_Cleaning_Gender.ipynb`](../week-0/assignments/Week0_Tutorial1_EnvSetup_and_Cleaning_Gender.ipynb)
- [`../week-0/assignments/Week0_Tutorial2_Advanced_Cleaning.ipynb`](../week-0/assignments/Week0_Tutorial2_Advanced_Cleaning.ipynb)
- [`../week-0/assignments/Week0_Tutorial3_Visualisation.ipynb`](../week-0/assignments/Week0_Tutorial3_Visualisation.ipynb)

Keeping the notebooks in `week-0/assignments/` preserves the week-by-week submission structure while this folder gives reviewers a fast place to find notebook work.

## How To Run

From the repository root:

```bash
python3 -m pip install -r requirements.txt
```

Then open the notebooks from `week-0/assignments/` in Anaconda, Jupyter, VS Code, or Google Colab.
